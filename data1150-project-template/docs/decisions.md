# Decision Log

_Record meaningful choices and the reasoning behind them so no one has to reconstruct them later. Newest at the top._

## Template

### YYYY-MM-DD: Short decision title
- **Decision:** What was decided.
- **Context:** What prompted it.
- **Options considered:** A, B, C.
- **Why this one:** Reasoning and trade-offs.
- **Who was involved:** 
- **Revisit if:** (conditions that would change this)

---

## Example (delete me)

### 2026-10-07: Use Python scripts instead of a spreadsheet macro
- **Decision:** Build the extraction step as a Python script.
- **Context:** Data arrives as PDFs, and a macro cannot parse them reliably.
- **Options considered:** Google Apps Script, manual entry, Python.
- **Why this one:** Python has stronger PDF libraries and can be wrapped in a simple command for non-technical users.
- **Who was involved:** Fellow, partner, TA
- **Revisit if:** Partner's team cannot install Python.
