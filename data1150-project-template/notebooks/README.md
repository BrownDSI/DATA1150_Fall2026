# Notebooks

Exploratory analysis and prototyping (Jupyter, Quarto, R Markdown, etc.).

## Conventions
- Name notebooks `NN-short-description.ipynb` (e.g., `01-explore-evaluations.ipynb`).
- Clear outputs before committing if they display sensitive data.
- Once something works, move reusable code into `src/`.
- Put a one-sentence purpose at the top of each notebook.
